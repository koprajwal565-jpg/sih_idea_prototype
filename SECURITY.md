# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

FixNear handles payments, consumer addresses, and professional identification documents. We take security vulnerabilities seriously.

If you discover a security issue, please **do not create a public issue**. Instead, send a detailed report to `security@fixnear.in` with:
- Type of vulnerability
- Step-by-step reproduction instructions
- Potential impact
- Suggested mitigations (if available)

We will respond within 48 hours to acknowledge receipt and coordinate a patch.
